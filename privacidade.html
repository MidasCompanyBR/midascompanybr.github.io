1.Quem somos

O Midas é um programa de uso interno da Midas Company. Ele roda no computador do dono da empresa e só acessa contas do próprio dono, com a autorização dele. Não é oferecido a outras pessoas.

2.Quais dados do Google o Midas acessa

  • Gmail, só leitura: remetente, destinatários, assunto, data e texto das mensagens das caixas do dono.
  • Gmail, na conta principal: ler, enviar e organizar mensagens, usado só quando o dono pede.
  • Google Drive: abrir, criar e editar documentos do Google Docs numa pasta de trabalho do dono.

3.Como os dados são usados

Só para o próprio dono: resumir e organizar o que chega por e-mail, avisar o que é urgente e editar documentos quando ele pede. Os dados não são usados para publicidade, não são vendidos, não servem para montar perfil de ninguém e não são usados para treinar modelos de inteligência artificial.

4.Onde os dados ficam

No computador do dono. As autorizações do Google ficam em arquivos protegidos, que só o usuário do computador abre. Os resumos e as notas ficam em arquivos do dono e podem ter uma cópia de segurança num repositório privado dele no GitHub.

5.Com quem os dados são compartilhados

Com ninguém, para nenhum fim próprio de terceiros. Para gerar os resumos, o texto pode ser processado por um modelo de inteligência artificial (Claude, da Anthropic), apenas para entregar o resumo ao dono.

6.Uso limitado

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7.Como tirar o acesso e apagar os dados

O dono pode tirar o acesso do Midas a qualquer momento em myaccount.google.com/permissions. As notas e os resumos são apagados apagando os arquivos no computador dele.

8.Mudanças

Quando esta política mudar, a data no topo muda junto.

Privacy policy (English)

Midas is an internal assistant of Midas Company, a Brazilian copywriting and digital strategy company. It runs on the owner's computer and only accesses the owner's own Google accounts, with his authorization. It is not offered to anyone else.

  • Data accessed: Gmail messages (read-only on the owner's inboxes; read, send and organize on his main inbox, only when he asks) and Google Drive documents in his work folder (open, create and edit Google Docs).
  • Use: only to summarize and organize the owner's incoming e-mail and edit his documents on request. Never for advertising, sale, profiling or training AI models.
  • Storage: on the owner's computer, with a possible backup in his private GitHub repository.
  • Sharing: none. To create summaries, text may be processed by an AI model (Claude, by Anthropic) solely to deliver the summary to the owner.
  • Limited Use: Midas's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: myaccount.google.com/permissions.
